# Caligraphia 0613 All-Platform Tracker

Last updated: 2026-06-13

This is the dated working ledger for the web, iOS, and Android parity push. The rule for all three clients is simple: once artwork is sent, shared surfaces display the server-owned `imageUrl`/`finalImageUrl` proxy so everyone sees the same letter regardless of the drawing engine that created it.

## Honest Gaps

- iOS and Android can send letters now, but recipient-specific addressing and ritual routing are still first-slice only.
- Android has a basic read-only detail reader, but not stamps/postscripts/scratch parity.
- iOS has a basic read-only detail, but not stamps/postscripts/scratch parity.
- Imported photos can be sent from both native apps, but richer share-in flows still need iOS extension work and Android direct-share shortcuts if recipient-targeted sharing matters.
- Native drawing tools have broader palettes, including watercolor and gold/illumination modes, but exact visual parity is intentionally anchored on the server-rendered uploaded image after send.
